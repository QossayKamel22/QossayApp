# NASAQ

### **Style in Every Detail.**

**NASAQ — نَسَق** is a modern Flutter e-commerce application focused on fashion and accessories, combining a clean mobile shopping experience with a carefully designed user interface.

The name **NASAQ (نَسَق)** represents harmony, arrangement, and personal style — the core idea behind the application's visual identity.

---

## ✦ Overview

NASAQ is a fashion-focused mobile shopping experience built with **Flutter and Dart**.

The application explores the complete foundation of a modern e-commerce experience, including product discovery, categories, user interaction, and a structured mobile architecture designed for future expansion.

The project places a strong emphasis on:

* Modern mobile UI/UX
* Fashion-oriented product presentation
* Reusable Flutter components
* Clean application structure
* Responsive layouts
* Smooth navigation
* Scalable architecture

## ✦ Architecture

The current application follows a modular Flutter structure:

```text
lib/
├── controllers/
├── models/
├── screens/
├── services/
├── widgets/
├── app_provider.dart
├── main.dart
├── root_widget.dart
└── user_model.dart
```

### Structure

**controllers/**
Application and screen-level logic.

**models/**
Data models used throughout the application.

**screens/**
Main application screens and user-facing pages.

**services/**
External and application-level services.

**widgets/**
Reusable UI components.

**app_provider.dart**
Central application state management.

**root_widget.dart**
Application root and primary widget configuration.

**main.dart**
Application entry point.

## ✦ Getting Started

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or physical device

### Clone the repository

```bash
git clone https://github.com/QossayKamel22/NASAQ.git
cd NASAQ
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
